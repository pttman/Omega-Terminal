# 个人终端产品需求文档

版本：v0.3 讨论稿

项目代称：Person Terminal（正式名称待定）

## 1. 已确认方向与草案边界

**已确认：做一款在 Windows 上统一使用本地 PowerShell 和 SSH 的终端产品，本地与远程兼顾。**

2026-11-13 范围调整：本地仅保留 Windows PowerShell 入口，移除 PowerShell 7（pwsh）和 CMD，旧的默认 Shell 设置自动迁移到 Windows PowerShell。下文涉及本地多 Shell 发现、选择、CMD 回退和兼容验收的原草案，以此调整为准；远程 Shell 配置与命令手册仍按对应环境提供。

2026-11-13 新增确认：

- 以 Termius 为主要视觉与交互风格参考。
- 第一版必须支持 Ctrl + 鼠标滚轮放大、缩小终端文字。
- 第一版必须支持将本地文件直接拖入 SSH 终端区域上传至对应服务器。
- 增加与当前会话关联的 AI 辅助与命令查询入口：使用自然语言描述需求，将生成的命令填入当前会话，减少跳到外部查命令。
- 必须支持命令自动补全。
- 连接阶段进度稍作停留，让快速连接也有平滑可读的过渡；取消、失败及时响应。会话支持拖动标签或分屏标题向左、右、上、下分屏，可嵌套布局、拖动分隔线调节比例，并拆回独立标签。

本稿将 AI 命令助手、命令手册及基础自动补全建议纳入 P0；先以一个可收起的助手面板承载，具体形态、服务接入和补全覆盖范围仍可讨论。

本文是共同讨论的起点。除上述方向与新增需求外，具体交互细节、版本划分和体验指标均为建议，尚未代表用户已确认。2026-11-13 用户已授权开始开发；当前预览版的实际实现、验证与待完成范围另见《实现与验证记录》，本需求文档仍描述目标行为。

第一版平台暂定 Windows 11 x64；是否兼容 Windows 10、ARM64 或其他系统，待实际设备与使用需求确认。

## 2. 产品定位

一句话定位：一个统一管理本地与远程会话，并能用自然语言查找、生成和补全命令的 Windows 桌面终端。

核心价值：常用入口集中、当前环境清楚、多个会话切换顺手；文字大小随手调整，传文件时可以直接拖入终端；想做什么就用自然语言提问，输入命令时能获得补全。

首要用户是我们自己。暂以个人开发与服务器维护为设计场景，需求成立与否优先用真实日常任务验证。团队协作与商业模式后续再讨论。

用户选择它的预期理由：打开后就能找到本地环境和常用服务器；切换时能清楚辨认目标；配置一次后，之后可以快速进入工作。

## 5. 核心使用场景

### 场景 A：打开本地终端

启动应用 → 自动发现可用的 PowerShell 与 CMD → 打开默认配置 → 在指定目录执行命令。

首次使用默认打开一个可用的 PowerShell；如果缺失，回退到 CMD 并解释原因。允许设置默认 Shell、启动目录、字体和主题。Shell 缺失或路径失效时，保留配置并提供修正入口。

### 场景 B：连接一台服务器

点击“新建 SSH 连接” → 填写名称、地址、端口、用户名和认证方式 → 保存并连接 → 核对首次连接的主机指纹 → 完成认证 → 进入终端。

下次从收藏、分组或搜索打开。连接失败时保留填写内容，并区分网络不可达、认证失败和主机身份变化等原因。

### 场景 C：同时进行本地与远程操作

打开本地 PowerShell → 新建 SSH 标签 → 将两个会话分屏 → 在本地查看项目，在远程查看运行情况。

每个分屏独立显示所属连接和状态。键盘输入只发往当前聚焦的分屏。第一版不提供多会话广播输入。

### 场景 D：断线后继续工作

远程连接断开 → 当前面板保留已显示输出 → 明确显示断线状态 → 点击重新连接 → 完成必要认证 → 建立新会话。

重连不重发上一条命令，也不宣称恢复远端进程。应用重启后的布局恢复与服务端会话续接是两个独立能力。

### 场景 E：随手调整文字大小

鼠标移到任一本地或 SSH 终端分屏 → 按住 Ctrl 滚动滚轮 → 向上放大、向下缩小 → 松开 Ctrl 恢复正常滚动。

无需进入设置，也不改变侧边栏和标签栏大小。当前分屏显示短暂的字号提示；支持一键恢复默认大小。

### 场景 F：把文件拖到服务器

从 Windows 文件资源管理器选取一个或多个文件 → 拖到目标 SSH 分屏 → 高亮显示上传区域、目标主机与目录 → 松手开始上传 → 在轻量传输面板查看进度与结果。

正常路径不要求先打开文件管理器面板。如果无法可靠确定目标目录，先在轻量浮层中选择目录；出现同名文件时选择覆盖、跳过或保留两份。上传与终端输入并行，完成后不自动执行文件或远端命令。

### 场景 G：用自然语言获得并填入命令

在某个终端分屏打开助手 → 输入“帮我查看谁占用了 8080 端口” → 助手按目标会话的系统与 Shell 生成命令及简短解释 → 点击“填入此会话” → 在终端中检查或修改 → 按 Enter 执行。

在本地 PowerShell 与远程 Bash 中，同一意图应生成分别适用的命令。目标环境未知时先选择环境或补充信息。已有输入不会被直接覆盖；切换会话不会让尚未完成的请求改投另一台机器。

### 场景 H：查命令与自动补全

想不起命令时，在助手的“命令手册”中搜索“查端口”“解压”“找大文件”等中文任务，看到适用于当前 Shell 的示例、参数说明和可编辑占位符，填写后插入终端。

已经知道命令时，直接在提示符中输入；出现命令名、已支持参数或路径候选，接受候选后继续编辑，最后按 Enter 执行。命令手册与基础补全在未配置 AI 服务或断网时仍可用。

| F13 | AI 命令助手 | 自然语言生成、解释命令；关联指定会话与 Shell；可编辑后填入；支持取消和重新生成 | 同一任务按 PowerShell、CMD、Bash 给出适用内容；目标可见、不自动执行、不误投其他会话 |
| F14 | 内置命令手册 | 中文任务搜索、Shell 筛选、用途、常用参数、示例、占位符填写与插入 | 无需 AI 服务也可离线查询；明确适用环境，参数未补齐时不能误当完整命令执行 |
| F15 | 基础自动补全 | 提示符输入时提供命令名、已覆盖参数、当前环境文件路径与当前会话已确认命令的候选 | 本地及受支持的 SSH Shell 可接受/忽略候选；中文与空格路径正确引用；补全不自动提交命令 |
| F16 | AI 服务配置与状态 | 配置服务地址、模型及凭据，连接测试、超时与错误反馈；可关闭 AI | 凭据受本机保护；配置错误或离线时终端、手册及基础补全正常工作 |

P0 的环境标识描述应用直接创建的会话。若用户在本地 Shell 内手动执行 SSH、再次跳转主机或切换用户，第一版不承诺自动识别最终身份；界面标注“启动配置”，避免把保存的连接名称当成实时身份。

P0 不新增跨会话命令历史数据库，保留 Shell 自身的历史行为；补全仅在内存中复用当前会话通过可靠集成确认提交的命令，退出会话后清除。无法可靠获得命令边界时不采集历史，不记录原始按键流。应用内输出搜索仍仅覆盖当前分屏内存中的内容。

F15 的基础覆盖建议为：PowerShell 5.1/7、CMD 和应用直接连接的 Linux Bash。完整候选菜单需要通过相应 Shell 的集成验证，不能从终端画面反推正在编辑的整行。CMD、受限服务器或集成不可用的环境，须至少保留 Shell 原生补全及助手中的候选查找/填入入口，并明确提示支持范围；如果达不到约定的基础体验，必须在需求评审中重新决定兼容范围，不能按完整自动补全验收通过。

### P1：提升重复使用效率

- 完整 SFTP 文件面板：远程目录浏览、下载、文件管理；拖入终端上传及其进度、取消、重名处理已纳入 P0。
- 文件夹拖拽上传、断点续传与应用重启后的任务恢复：在 P0 文件上传稳定后扩展。
- 工作区：保存标签、分屏与配置引用，再次打开时创建新会话；远程连接需要显式触发或用户启用自动连接。
- 命令片段：名称、说明、适用 Shell、内容；选取后先填入命令输入区，由用户执行。
- WSL 与 Git Bash 配置入口，按实际安装情况发现。
- SSH Agent、跳板机与端口转发，按真实服务器连接要求决定顺序。
- SSH 配置导入：预览可识别字段、冲突与不支持项，再执行导入。
- 短暂断线自动重试：可配置次数、间隔与取消，不自动重放命令。
- 扩大补全范围：更多命令与参数规格、项目与工具版本感知、跨会话历史、其他远程 Shell。
- AI 错误分析：用户选取一段输出后解释原因、生成排查建议；默认不会自行扫描全部终端内容。
- AI 预测后续命令：按需启用，作为基础补全的额外候选，单独显示来源。

### P2：进一步探索

- 命令块、命令耗时、退出码与按命令检索；先验证不同 Shell 的集成条件。
- AI 工作台增强：多步骤任务规划、跨会话对比、工作流保存；是否加入可执行代理需另行定义授权与交互，本稿不包含自主执行循环。

第一版范围外：图形远程桌面、内置代码编辑器、批量服务器执行、云账号体系、自研 Shell、服务端代理部署。

## 7. 界面与交互草案

已确认以 Termius 为主要风格参考。建议落地为深色分层背景、简洁侧边导航、清晰的分组与主机卡片、紧凑标签栏、适度圆角与留白，辅以克制的强调色。具体色值、间距和组件形态在原型阶段确定；使用本项目自己的名称与图标资源。

默认采用深色主题，提供浅色主题；应用界面优先中文。布局尽量稳定，让终端内容拥有主要空间。本地 PowerShell/CMD 入口与远程主机保持同等可达性。

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 左侧可收起导航 | 本地配置、收藏、服务器分组、最近使用 | 搜索或选择后打开会话；编辑入口与连接入口分开 |
| 顶部标签栏 | 当前会话标签、新建菜单 | 显示会话类型与名称，支持关闭和切换 |
| 主内容区 | 终端与分屏 | 聚焦边框清晰；每个分屏有身份与状态信息 |
| 右侧可收起助手 | “AI 助手 / 命令手册”两个页签，顶部显示目标会话 | 默认关联唤起助手的分屏；生成结果可解释、编辑和填入；手册可离线使用 |
| 按需面板 | 主机详情与连接编辑、设置、上传队列；后续完整文件面板 | 上传队列轻量展示状态，完整文件面板无需常驻 |

主机颜色用于辅助识别，同时显示“生产”“测试”等文字。无服务器时展示“新建 SSH 连接”，同时保持本地终端可直接使用。

建议快捷键：Ctrl+Shift+T 新建默认终端，Ctrl+Shift+P 打开命令面板，Ctrl+Shift+F 搜索输出，Ctrl+Tab 切换标签，Ctrl+Shift+C/V 复制/粘贴。提供快捷键设置与冲突提示；尽量保留终端程序对 Ctrl+C、Tab 和方向键的使用。

### 7.1 Ctrl + 滚轮缩放细则（建议）

- 作用范围：鼠标所在的终端分屏，适用于 PowerShell、CMD 和 SSH。侧边栏、标签栏和其他分屏大小保持各自设置。
- 手势：按住 Ctrl 向上滚动增大字号，向下减小；按标准滚轮刻度每步调整 1 px。触控板高精度滚动累积到阈值后调整，避免一次跳变多个字号。
- 建议字号范围 8–40 px；默认 14 px，实际默认值在原型中校准。到达边界后停止调整。
- 显示短暂的字号提示，提供“恢复默认字号”；Ctrl+0 作为建议快捷键，可修改或关闭。
- 接管 Ctrl + 滚轮，避免同时触发整页缩放、历史滚动或把该滚轮事件传给远程程序；不按 Ctrl 时维持正常终端滚动行为。
- 字号变化后重新计算终端行列数并同步尺寸；已有输出和当前输入保留，全屏程序可以按新尺寸重绘。
- 当前分屏的字号在其生命周期内保留；新建分屏采用全局默认字号。用户可以在设置中显式修改默认字号。后续保存工作区时再恢复各分屏字号。

### 7.2 拖拽上传细则（建议）

**目标与目录**

- 拖到哪个 SSH 分屏，就上传到该分屏所绑定的连接；与键盘焦点是否处于该分屏无关。释放鼠标时固定目标，切换标签不会改写已排队任务的目的地。
- 拖入时展示“上传到 用户@主机:端口 /目标目录”，用高亮边界明确接收区域。目录未知时显示“松开以选择上传目录”，不展示猜测路径。
- 优先使用可可靠获取、属于同一连接且未失效的远程 Shell 当前目录；没有可靠目录信息时，使用用户为该会话明确选择或配置的上传目录。Shell 目录同步方式在技术验证阶段确定，不能仅从提示符文本猜测。
- 两者均不可用时，在首次拖入后用轻量目录选择浮层设置目标，默认展示远程用户主目录；用户确认后开始上传。后续拖入可直接上传到该已选目录，并始终展示实际路径。
- 当前工作目录与手选上传目录的来源要可辨认，可随时切换或修改。如果之前可靠的 Shell 目录信息已失效，重新要求选择，不悄悄切换到其他目录。

**文件与传输**

- P0 支持本地单文件、多文件，包括中文、空格及特殊字符文件名；按协议传递路径，不拼接 Shell 上传命令。
- P0 拖入文件夹时，明确提示暂不支持，并提供取消入口；混合选择时先列出可上传文件与不支持项，由用户选择是否继续文件部分。
- 在已认证、身份一致的 SSH 连接上使用 SFTP；若需新建传输连接，应重新校验主机身份并按需认证。服务器不支持 SFTP 时显示具体原因，终端继续可用。
- 传输队列展示文件名、目标、已传/总大小、进度、速度及状态；支持单任务取消、失败后重试，多文件逐项显示结果。取消后保留已完成项，只停止未完成任务。
- 建议同一连接最多并行 2 个文件，其余排队；大文件分块处理，内存占用不随文件大小线性增长。
- 同名时提供覆盖、跳过、保留两份，可将选择应用于本次批次；默认等待选择。保留两份应生成不冲突的新文件名。
- 优先上传到唯一临时文件，成功后再提交为目标名称；用户取消、传输失败或最终重命名失败时，显示已完成情况及临时文件清理结果。覆盖前先保证原文件仍在；服务器不支持安全提交时说明限制，不静默删除原文件。
- 网络中断时标记失败或中断，不自动从头重复上传；用户可重新开始，P0 不承诺断点续传。应用退出时有活跃传输应提示，取消退出后任务继续。
- 同一文件重复拖入且已有相同目标的活动任务时提示，避免无反馈地新增重复任务。

### 7.3 本地终端与特殊会话的拖拽行为（建议）

- 文件拖入本地 PowerShell/CMD 时，默认插入经过对应 Shell 正确引用的本地路径，不自动执行命令；保留“拖入文件即可使用”的本地体验。
- 上传只面向应用管理的 SSH 连接。本地 Shell 内手动执行 ssh、嵌套跳板或切换用户后，不能据此推断新的上传主机或权限；拖拽提示仍应清楚显示应用实际绑定的目标。
- 远程终端中的 vim、top 或密码输入不接收本地路径或上传命令，上传由应用的独立传输流程完成。
- 对未连接、认证中或已经断开的 SSH 分屏，提示先完成连接，不暗中改为本地路径粘贴。

### 7.4 AI 助手与自然语言命令（建议）

**入口与呈现**

- 侧边助手用于稍长的提问与追问；另提供从当前分屏唤起的轻量自然语言输入框，适合“查端口”“列出大文件”等快速操作。两个入口共享同一套生成与目标会话逻辑。
- 自然语言在专用输入框输入，普通终端输入继续按 Shell 原有方式工作，不会把普通文本自动发给 AI。
- 结果优先展示一条最符合需求的命令、用途及关键参数；必要时提供备选。多步任务逐条展示，用户逐条填入和执行。
- 标明建议适用的系统、Shell 以及额外工具依赖。工具是否安装未经验证时明确标注，不把猜测当成已验证结果。

**会话与填入**

- 提问时固定目标会话 ID、连接实例、系统和 Shell；在请求与结果上始终展示目标。用户切换标签不改变进行中请求的绑定，可以显式切换助手目标。
- 若目标断线、关闭或重连为新实例，原建议仍可查看、复制，但应在重新确认目标后才能填入。新选目标应重新适配命令，不能只换展示的名称。
- 默认操作为“填入此会话”，只放入可编辑命令缓冲区，不附加回车。第一版不提供生成后自动执行或失败后自动重试命令。
- 当前输入非空时提供“保留现有输入并暂存建议”或“替换输入”，不默认覆盖，也不将两条命令直接拼接。目标程序忙碌、处于密码提示、全屏程序或无法确认提示符就绪时，暂存建议，仍可复制。
- 多行脚本先展示完整内容，并与已有多行粘贴预览合并为一次操作；未填写的端口、路径、文件名等占位符在面板内补齐后再填入。
- 自然语言含糊或缺少关键条件时，在助手中追问。涉及删除、覆盖、权限变更等操作，在结果旁解释具体影响，不额外插入反复确认弹窗。

**上下文与服务**

- P0 默认只发送用户的提问及必要环境信息，例如 Windows/Linux、PowerShell/CMD/Bash 与已知版本；主机真实地址、终端输出、历史命令、目录内容不自动附带。环境信息在请求旁可查看和修正。
- 用户可显式附加选中的输出、目录或手工补充信息，发送前可查看并移除；不自动采集密码输入、私钥或后台会话。
- 默认建议采用用户自行配置 AI 服务地址、模型与 API 凭据的方式，具体供应商、是否支持本地模型以及费用方案待定。与 SSH 认证凭据分开管理，应用无需云账号。
- 展示生成中、取消、超时、限流、鉴权失败与离线状态；失败保留问题，可重试。API 凭据不进入普通配置导出或诊断日志；凭据保存使用 Windows 凭据保护能力。
- 助手会话与上下文 P0 只在当前应用会话内存中保存，提供清空入口；是否本地持久化作为后续设置决定。

### 7.5 内置命令手册（建议）

- 与 AI 共用助手空间，可独立离线使用。按意图、命令名和参数检索；先按目标 Shell 筛选，允许用户切换环境。
- 首批建议覆盖：目录与文件、文本搜索、进程与端口、磁盘与资源、压缩解压、权限与常用网络检查。Git、Docker 等额外工具单独标识安装前提与适用版本。
- 条目包含中文用途、命令名、适用系统/Shell、常用参数、可填写示例、来源及维护版本。不同 Shell 的写法分别维护，不直接互换。
- 示例中涉及具体路径、端口或文件名时提供填写字段。支持“复制”“填入当前会话”“请 AI 解释”，其中 AI 解释仅在配置服务后可用。
- 内置示例同时作为已支持参数补全的规格来源；维护可检查的覆盖清单。第一版不承诺覆盖所有系统工具或自动安装缺失工具。

### 7.6 命令自动补全（建议）

**候选内容与边界**

- 命令名：来自相应 Shell 可可靠提供的内建命令、可执行程序等；命令手册可作为补充来源，并标记可能需要安装的工具。
- 参数：按当前命令与适用版本的已维护规格提供名称、取值与简短说明；没有对应规格时不编造参数。
- 路径：从当前执行环境取得候选。本地终端使用本地路径；SSH 会话使用相应远程主机可访问的路径。SFTP 目录与 Shell 目录不一致时不冒充当前路径补全，回退到经验证的 Shell 能力。
- 历史：只使用当前会话已可靠确认的命令；支持删除单条候选。本地、远程及不同分屏的历史不混用。
- 基础补全由本地规则与 Shell 能力驱动，不依赖 AI 请求。AI 生成整条命令属于显式提问或后续可选增强，不逐次上传键盘输入。
- 补全只在可靠识别的 Shell 提示符编辑阶段启用；密码输入、运行中程序、vim/top、多行续写状态未支持时不弹出候选，不注入探测命令到用户终端。
- 远程集成仅在用户创建连接或启用时按说明加载；不为补全默认安装常驻代理。受限环境有原生补全与助手填入的回退入口。

**键盘与更新**

- 默认显示简短候选列表，可附带轻量灰字建议；候选标注来源，不替换用户实际输入。
- 候选列表可用方向键选取、Tab 接受、Esc 收起；接受只修改命令缓冲区，不执行。候选收起时按原样将 Tab 等按键交还 Shell。
- Enter 用于用户正常提交终端命令，不因候选列表弹出而自动换成另一条命令；灰字尚未接受时不属于已提交内容。
- 用户可以关闭应用补全、保留原生补全，或修改接受快捷键；不得破坏 Ctrl+C、输入法选词或交互程序按键。
- 仅替换当前光标对应的补全部分，保留其余输入；按目标 Shell 引用中文、空格和特殊字符路径，不复用其他 Shell 的转义方式。
- 输入变化、切换目录或会话后，取消或丢弃过时结果；远程候选查询慢或失败时可继续正常输入，不能把旧目录结果填入新位置。
- 建议本地已缓存候选展示 P95 不超过 150 毫秒；远程候选采用异步查询及有限缓存，显示加载状态、可取消，不设依赖网络的固定完成时限。

## 8. SSH 与数据处理要求

以下属于连接与数据功能的基本要求，不作为额外弹窗清单。

- 首次遇到未知主机时展示主机、端口、指纹与信任选项；主机密钥变化时停止连接，提供核查与更新入口。
- 输入密码前先检测服务器地址和 SSH 服务可达性；检测期间显示平滑阶段进度，支持取消与失败重试。检测通过后提供“保存并连接”和“直接连接”两个操作按钮；选择保存且认证成功后使用 Windows 凭据保护能力加密保存在本机，普通配置导出不携带密码；下次连接可直接使用。编辑连接中提供清除入口，修改地址、端口、用户名或认证方式后旧密码失效。
- 私钥口令仅在当前认证过程使用，不持久保存。私钥默认引用本地文件，不复制进应用配置；密码默认不回显，可临时切换显示。小窗口表单支持滚动。
- 普通配置导出包含名称、地址、用户名、分组与显示设置；不包含密码、私钥内容、口令、信任记录或终端输出。私钥路径默认不导出，导入后由用户重新指定。
- 主机指纹信任记录与普通连接配置分开管理，不能因导入配置而自动建立信任。
- 配置存本机用户目录；P0 无需应用云账号。默认不采集或上传终端输入与输出；AI 请求仅在用户提问时发送约定的最小上下文，附加输出由用户显式选择。应用诊断日志不记录认证内容。
- 多行粘贴先预览并确认；支持时使用终端的括号粘贴能力，不能承诺所有 Shell 都有相同行为。
- 不把用户键盘输入流直接当作命令历史采集，避免记录密码及交互程序输入。
- 上传目录权限不足、磁盘空间不足或文件不可读取时显示明确原因，不自动提权。上传文件路径与内容不写入普通配置导出。
- 终端输出、手册内容与附加文本仅作为 AI 参考数据，不得据其中的文字指示扩大上下文、发送其他会话数据或执行命令。实际填入始终遵循目标会话绑定与用户操作。

## 9. 兼容性与体验目标

以下为待实测的验收目标，不是当前已达到的指标。建议基准环境为 Windows 11 x64、16 GB 内存、SSD；实施时记录系统版本、机器配置与测试数据集。

| 项目 | 建议目标 | 测量口径 |
| --- | --- | --- |
| 冷启动 | 10 次测试的 P95 不超过 3 秒 | 从启动到默认本地终端可输入；记录 Shell 配置开销 |
| 标签切换 | 20 次测试的 P95 不超过 100 毫秒 | 8 个空闲会话间切换至目标内容可交互 |
| 空闲资源 | 1 个本地会话运行 60 秒后，应用进程树内存目标低于 300 MB | 同时报告应用组件与 Shell 子进程的占用；技术验证后调整预算 |
| 输出压力 | 持续输出期间仍能输入、切换与滚动 | 使用固定数据集与速率验证，回滚缓冲区有上限；达到上限淘汰最旧内容 |
| 缓冲区 | 默认每个分屏保留最多 10,000 行 | 提供可调整上限，搜索不包括已淘汰内容 |
| 长时间使用 | 连续使用 8 小时无崩溃，反复开关会话后无持续资源增长 | 记录至少 50 次会话创建与关闭前后的资源情况 |
| 基础补全 | 本地已缓存候选展示 P95 不超过 150 毫秒 | 在明确的命令与路径数据集上从输入稳定到候选显示计时；远程查询单独记录网络耗时 |
| AI 故障隔离 | 未配置、断网、超时或限流不影响终端与基础补全 | 模拟服务不可用，仍能输入、执行命令、查询离线手册与切换会话 |

兼容验证覆盖：Windows PowerShell 5.1、PowerShell 7、CMD；SSH 至 Linux 的 Bash；中文输入法、中文路径、ANSI 颜色、缩放与高 DPI。远程交互至少验证 vim 与 top 的全屏刷新、方向键、Ctrl+C、终端尺寸变化。字符编码允许按配置调整；具体版本矩阵在技术验证时确定。

键盘可访问所有主要操作，聚焦状态可见；图标按钮有可读名称。颜色不能成为区分环境与状态的唯一信息。

## 10. 首版验收任务

1. 全新启动应用，不注册账号即可使用 PowerShell 或 CMD；没有可用 Shell 时看到可操作的错误提示。
2. 新建一个指定工作目录的本地配置，重启后仍可打开。
3. 创建 SSH 连接，分别验证交互式密码认证和带口令私钥认证；取消认证后可重试。
4. 首次主机信任可拒绝；模拟主机密钥变化后连接停止，并显示原因。
5. 同时打开本地与两个远程会话，完成分屏、切换与独立输入，能辨认当前目标。
6. 输出中英文文本、调整窗口大小，完成查找、选择与复制；粘贴多行时可取消。
7. 中断网络后显示断线、保留当前输出；重新连接后不自动执行断线前的命令。
8. 保存、导出并重新导入连接配置，检查导出文件无密码、私钥内容或终端输出。
9. 关闭活跃会话时可以取消；确认关闭后对应本地子进程或 SSH 连接得到清理。
10. 完成一次真实的“本地项目操作 → 连接服务器 → 查看日志 → 切回本地”的日常任务，记录阻碍与额外步骤。
11. 在 PowerShell、CMD 和 SSH 中分别按住 Ctrl 上下滚轮，确认只调整鼠标所在分屏字号、达到边界后停止；恢复默认可用，终端内容、当前输入和其他界面大小不变。
12. 在 vim/top 中缩放后检查行列更新与显示；释放 Ctrl 后普通滚动恢复，Windows 显示缩放 100%、150%、200% 下手势均可用。
13. 将一个文件和多个文件分别拖到不同 SSH 分屏，检查高亮区域、主机及目录与实际目标一致；传输前后比较文件内容摘要，中文与空格文件名正确。
14. 可靠目录跟随 Shell 的 cd 更新；目录未知时先选择，已选目录可复用和修改；在本地终端手动 SSH 后不误传至该手动连接目标。
15. 验证同名覆盖、跳过、保留两份，以及断网、取消、权限不足、SFTP 不可用、混合文件夹选择、重复拖入和应用退出；原文件不被静默覆盖，失败与清理结果可见。
16. 拖入大文件（例如 1 GB）及多文件队列时仍可输入和切换终端；上传过程中内存占用不随累计传输字节持续增长。
17. 拖文件至本地 PowerShell/CMD 时只插入正确引用的路径；文件名含中文、空格和特殊字符时仍不自动执行；拖到断线 SSH 或远端交互程序时不误粘贴路径或命令。
18. 用相同中文请求在 PowerShell、CMD 和 Linux Bash 生成命令，检查系统、语法和依赖提示；填入后未按 Enter 前不会执行，命令可以修改。
19. 在会话 A 发起请求后切换到 B，结果仍绑定 A；A 断线、重连或关闭后不会把旧命令直接投递到新实例。当前输入非空、密码提示或程序忙碌时可暂存，不破坏已有输入。
20. 未配置 AI 或断网时，按中文任务检索离线手册、填写示例参数并插入；AI 配置、取消、超时、限流和错误反馈可用。
21. 核查实际 AI 请求只包含提问与已展示的必要环境信息，附加输出可预览和移除；其他分屏、密码、私钥和原始按键不被发送或写入历史。
22. 在约定的 Shell 与命令覆盖清单中验证命令名、参数、路径和当前会话命令候选；Tab 接受、Esc 取消、Enter 提交当前实际输入，未接受的建议不会执行。
23. 在中文输入法、特殊字符路径、远程延迟、连续输入、目录与会话切换下验证补全；过时结果被丢弃，其他主机的路径与历史不混入，全屏程序和密码输入不触发补全。
24. 集成不可用或不支持的 Shell 明确显示能力范围，原生补全与助手查找可用；验收记录区分完整应用补全与回退能力，不能把后者记作前者。

## 12. 下一轮讨论

已确认：Termius 为主要风格参考，Ctrl + 滚轮缩放和拖入 SSH 终端上传属于第一版必需；新增自然语言命令辅助与自动补全需求。本稿建议用 AI 助手/命令手册统一承载，基础能力纳入 P0。完整双栏文件管理和下载仍列 P1。

后续优先讨论这两个问题：

1. 平时最常做的三个终端任务是什么？例如运行本地项目、Git 操作、连接 Linux 服务器、查看日志、传文件。
2. 除直接拖文件上传外，是否经常需要拖文件夹、浏览服务器目录或下载文件？目前这些增强能力列 P1。

后续确认：实际 Windows 版本、服务器数量及认证方式、是否需要跳板机、Termius 中特别喜欢的具体界面细节、正式名称、是否面向其他用户发布。

AI 与补全专项待确认：优先接入的 AI 服务或本地模型、服务凭据与费用方式、最常查询的命令类型，以及首批必须完整支持补全的 Shell/工具。默认建议先做单次提问生成与填入，不引入自主执行工作台。
