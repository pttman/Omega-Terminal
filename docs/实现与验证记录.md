## v0.1.0 发布验证（2026-11-13）

- TypeScript 检查与生产构建通过；29 项自动化测试通过，覆盖真实 PowerShell、SSH/SFTP、配置与加密凭据、补全、布局和 AI 适配。
- 直接解压最终发布 ZIP 并测试 `Omega Terminal.exe`，前端资源、主进程与 preload 均与本次构建逐字节一致；未混入开发配置、缓存、报告或旧版本。
- 版本与退出专项 4 组检查通过：显示真实版本和运行环境；标题栏关闭、原生窗口关闭和应用退出使用同一弹窗；取消保持 PTY 运行；重复关闭不堆叠；旧请求不可确认；键盘焦点、浅深主题、减少动态效果及实际退出过渡正常。
- SSH 连接专项 13 组检查通过：连通性预检、密码单一焦点边框、输入密码时停在 82% 认证阶段、实际连接成功后才完成、无第二次加载卡片、加密密码重启恢复、失败重试、防重复连接、小窗口、取消和减少动态效果。
- 动效与传输专项 5 组检查通过：外观/登录信息/传输移出 1 秒收起，移回取消；进出可逆过渡；传输默认 3 条，展开后高度不变且可滚动；命令栏、搜索、助手与弹窗存在实际中间帧。
- 综合桌面冒烟 10 项检查通过：中文命令输出、Tab 补全、终端字号、手册/AI 填入、双 PTY 分屏、SSH 指纹与原生文件拖放上传，无未捕获渲染错误。
- SSH 与 AI 自动化仅使用绑定本机的隔离测试服务。报告、截图、测试配置位于 `test-results/`，不进入 Git 或发布包。

部分环境在 PTY 清理阶段会使 node-pty 的控制台助手输出 `AttachConsole failed`；29 项测试断言全部通过。仍需在更多 Windows 环境中观察退出清理的兼容性。
