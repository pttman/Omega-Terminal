# Omega Terminal

面向 Windows 的个人桌面终端。统一使用本地 PowerShell 与 SSH，提供拖拽上传、随行助手和内置命令手册。

当前版本：0.1.9 开发预览版。产品设计与尚待完成的范围见 [产品需求文档](docs/产品需求文档.md)，实际交付情况见 [实现与验证记录](docs/实现与验证记录.md)。

## 直接使用

从 [GitHub Releases](https://github.com/pttman/Omega-Terminal/releases) 下载 `Omega-Terminal-Setup-0.1.9-x64.exe`，双击运行中文安装向导，可选择安装目录并创建桌面/开始菜单快捷方式。默认安装到当前用户，安装后可从 Windows“已安装的应用”中卸载。面向 Windows 11 x64，预览版未签名。

同时提供 `SHA256SUMS.txt`，可用 `Get-FileHash .\Omega-Terminal-Setup-0.1.9-x64.exe -Algorithm SHA256` 核对下载完整性。

启动后直接显示连接配置列表，无侧栏；顶部提供搜索、新建连接、本地终端、分组/收藏筛选和卡片/列表切换。连接卡片双击打开（键盘 Enter / 空格也可连接），悬停可收藏、编辑或删除；编辑与删除分开排列，删除前需确认。

本地终端：点击配置列表工具栏中的 Windows PowerShell。本地仅保留此入口，旧的 PowerShell 7 / CMD 默认设置自动迁移到 Windows PowerShell。原生终端支持直接输入；底部命令栏提供应用补全、命令编辑及 AI/手册填入。按 Enter 执行命令栏中的实际内容。执行后焦点留在命令栏，可以继续输入；上一条由命令栏提交的普通命令仍在运行时，新命令按顺序等待 Shell 提示符后执行，最多待执行 20 条，终端持续显示输出。命令栏中 Ctrl+C 或停止按钮可中断当前命令并清空队列；也可以单独清空待执行命令，保留当前命令运行。原生输入未清空时先点清空终端输入。

Vim、less、top 等交互程序及终端全屏交互界面运行时，命令栏暂停，待执行队列自动清空，输入交给原生终端。退出并返回 Shell 提示符后自动恢复命令栏。

分屏：拖动顶部会话标签或分屏标题，到另一个终端的左、右、上、下边缘，看到预览后松开即可移动已有会话；最多四个分屏，可组合左右与上下布局。拖动分隔线调整比例，双击恢复均分；聚焦分隔线后也可使用方向键调整、Home 恢复均分。拖动时悬停其他标签可切换目标；拖到顶栏“松开以独立标签”区域可将分屏拆成独立标签。原连接、输出和输入草稿会保留。

远程连接：点击“新建连接”，从右侧展开面板，只需填写地址、用户名、端口（默认 22）和认证方式；选私钥认证时再选择私钥。名称默认使用地址。保存操作固定在底部，按 Esc 或右上角关闭按钮可收起。连接前先检测地址与 SSH 服务，平滑进度条显示实际阶段；连通后再输入密码或私钥口令，并核对主机指纹。密码页提供“保存并连接”和“直接连接”：前者在认证成功后使用 Windows 系统加密保存在本机，下次可直接连接，后者不保存本次密码。编辑连接中可以清除密码；修改地址、端口、用户名或认证方式后旧密码自动清除。私钥口令只用于此次连接。较小窗口中的表单可以滚动。

SSH Bash 终端在初始化完成后显示干净的提示符，初始化脚本不会刷屏；服务器欢迎信息、最近登录等收在右上角可展开的“登录信息”中。后续命令输出正常显示，不修改远端登录配置。Bash 提示符中的主目录标记与下级路径留出空格，例如 `Ω ~ /yiask #`；实际工作目录保持原样。

连接进度按实际已完成的阶段平滑推进，快速预检约用 1.5 秒呈现完整过渡；较慢的网络仍按实际耗时等待，取消和失败即时响应。系统启用减少动态效果时跳过这段展示延迟。

上传：从文件资源管理器拖一个或多个文件到 SSH 终端区域，上传至可靠识别的工作目录；未识别时先选择目录。已有连接配置中的固定上传目录继续生效。右下角查看进度、取消或重试。默认展示最近 3 条，展开后在固定高度内滚动。文件夹上传尚未实现。

AI：打开“设置 → AI 服务”，填写兼容 Chat Completions 格式的基础地址、模型名与凭据。本机模型可使用 localhost HTTP；远程服务使用 HTTPS。需要自行准备可用服务，未内置付费凭据。助手生成建议后点击“填入原会话”，检查后按 Enter 执行。

手册：不配置 AI 也能使用；包含 PowerShell、CMD 和 Linux Bash 的常用任务示例。切换终端标签或聚焦分屏时，自动显示该会话对应的命令类型；手动选择其他类型后，切换窗口会恢复自动匹配。选择条目、填写参数，再复制或填入当前终端。

缩放：鼠标置于终端，Ctrl + 滚轮调整该分屏字号；Ctrl+0 恢复默认。普通滚轮仍滚动终端。

窗口：顶部「连接」标签返回配置列表。连接会话中点击右上角全屏按钮或按 F11，只显示终端内容；最大化连接窗口时同样隐藏所有应用界面。再按 F11 恢复界面，Esc 保留给终端程序。分屏和输入草稿会保留。需要确认粘贴或退出时先恢复界面显示确认框。

光标与字体：终端使用 JetBrains Mono 等宽字体，输入光标为一个字符宽的粉色方块，浅色主题使用深粉色，光标内文字自动使用清晰的深色或白色。SSH Bash 的 `ls` 目录以蓝色粗体显示；颜色设置仅作用于当前会话，保留用户已有的 `ls` 别名/函数及其他文件颜色。

复制：选中终端内容后按 Ctrl+C、Ctrl+Shift+C 或 Ctrl+Insert，也可以点击分屏顶部的复制按钮，或右键选择“复制”。复制时自动去掉提示符的 Ω 和紧随其后的 `~ ` 前缀，保留命令与输出中的正常 Ω、~、缩进与换行。没有选区时 Ctrl+C 仍用于中断命令。

外观菜单、登录信息和传输面板在鼠标离开 1 秒后收起，移回可取消收起。右下角版本号可打开关于信息；有活动会话或传输时，退出会显示随主题变化的应用内确认弹窗。

## 开发

建议使用 Node.js 24 LTS、npm 与 Windows 11 x64。本项目锁定依赖版本，使用 Windows ConPTY。

```powershell
npm ci
node node_modules/electron/install.js
npm run dev
```

Electron 45 需要单独下载运行文件；若下载失败可按本机网络环境配置 Electron 官方支持的镜像，再执行安装命令。

```powershell
npm run build
npm start
npm test
npm run test:desktop
npm run test:assistant
npm run test:clipboard
npm run test:fullscreen
npm run test:connections
npm run test:ui-credentials
npm run test:split
npm run test:motion
npm run test:app-dialogs
npm run pack
npm run test:packaged
```

`test:desktop` 会打开隔离的测试窗口，并创建仅绑定 127.0.0.1 的 SSH/SFTP 与 AI 测试服务；不会连接用户的真实服务器或真实模型。报告与截图位于 `test-results/`。

开发配置保存在项目 `.local-data/`；打包版配置保存在 Windows 用户应用数据目录下。API 凭据与用户选择记住的 SSH 密码通过 Electron safeStorage 使用 Windows 系统保护；普通配置导出不包含凭据、私钥路径和信任记录。聊天与当前会话命令历史只保存在内存。

## 项目结构

| 目录 | 内容 |
| --- | --- |
| `electron/` | 桌面窗口、受限 IPC、本地 PTY、SSH/SFTP、配置与 AI 适配 |
| `src/` | React 界面、xterm.js 终端、命令输入栏、手册与助手 |
| `src/shared/manual.json` | 离线命令条目与适用 Shell |
| `tests/` | 命令引用、配置、真实 PTY、SSH/SFTP、AI 服务测试 |
| `scripts/desktop-test.mjs` | Electron 界面与原生文件拖放端到端验证 |

## 目前边界

- 应用候选补全位于底部命令输入栏；直接在原生终端输入时由 Shell 提供原生补全。尚未把应用候选菜单嵌入所有 Shell 的原生编辑缓冲区。
- SSH Bash 会话会加载仅当前会话有效的提示符函数以获取目录与就绪状态，不修改服务器文件。受限服务器或其他远程 Shell 可能只支持原生终端；无法确认空白提示符时，命令栏不自动投递。
- 参数补全目前是有限的静态规格；远程命令名候选是常用命令目录，不能证明对应工具已安装；路径候选通过本机文件系统或同连接 SFTP 查询。
- 跳板机、SSH Agent、端口转发、文件夹上传、下载面板、断点续传、工作区恢复、自定义快捷键编辑尚未实现。
- 尚未在真实生产服务器、长时间压力、高 DPI 多档和中文输入法组合中完成全面验收。AI 接口用本机测试服务验证，真实供应商仍需接入测试。
- Windows 预览版未签名；已提供 Setup 安装向导，暂未提供自动更新。

## 打包与发布

运行 `npm run release`（或 `npm run release:setup`）生成 `artifacts/Omega-Terminal-Setup-0.1.9-x64.exe` 与 `SHA256SUMS.txt`。默认发布 Setup 安装程序；`npm run release:zip` 仅用于需要免安装包时。发布范围与检查步骤见 [发布说明](docs/发布说明.md)。源码仓库只保留构建所需的代码、资源、锁文件、测试与文档。
